# RhulanyTech

Loja online de tecnologia e gaming feita com React, TypeScript, Vite e Tailwind CSS.

## Comandos

```bash
npm install      # instalar dependências
npm run dev      # servidor de desenvolvimento
npm run build    # build de produção (pasta dist/)
npm run preview  # pré-visualizar o build
```

Copia `.env.example` para `.env` e preenche as chaves (Gemini, Supabase, etc.).
